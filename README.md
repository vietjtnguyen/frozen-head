# Frozen Head

A simple web image viewer that holds a frozen pane of the top of an image allowing you to explore very large sequence diagrams without losing context for what each swim lane represents.

## Usage

Just open `index.html`. The viewer is self contained and is also hosted on GitHub pages: <https://vietjtnguyen.github.io/frozen-head>

## Example

A diagram of what happens when you press Enter in the URL bar, 16 lanes and over 10000 px tall, with the title line skipped and just the lane boxes frozen:
